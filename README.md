# 萬夫不當（ばんぷ ふとう）

三国志の武将で乱軍を薙ぎ払うホードサバイバル。Halls of Torment の骨格を三国志に移した一本。

**遊ぶ** → https://ngmt4amtk-web.github.io/banpu-futou/

## これは何か

- 動かすだけ。攻撃は自動。指一本で万の兵を薙ぐ
- 倒すと**装備が落ちる**。抽選の引き金が自分の攻撃なので、殴る快と引く快が同じ動作になる
- 拾った装備は保管庫に永久に残り、次の出陣に持ち込める
- 神品（伝説装備）は全13種。一度出たものは二度出ない＝集め切るまで金は褪せない
- 戦功を錬兵所に注いで永続強化。死んでも持ち帰る

## 中身

- 武将10人（関羽・張飛・趙雲・呂布・諸葛亮・黄忠・夏侯惇・甘寧・孫尚香・許褚）。武器の型が5種で手触りが違う
- 戦場5つ（広宗・虎牢関・長坂坡・赤壁・五丈原）。各戦場に大将（張角・呂布・曹純・蔡瑁・司馬懿）
- 技22種（副武装10＋能力強化12）。1回の出陣で副武装は6つまで
- 装備6部位 × 4階級（常品・良品・名品・神品）、接頭辞12種

## つくり

依存ゼロの静的Web。画像アセットを一枚も使わず、人型も馬も地面もコードで描いてオフスクリーンに焼いている（90年代末のプリレンダCG風はその副産物）。音も Web Audio で合成。

- `data.js` 武将・敵・戦場・技・装備の定義
- `gfx.js` スプライトのプリレンダ、効果音
- `game.js` ゲーム本体（更新・描画・自己検証）
- `ui.js` 画面遷移とUI

## 開発用

- `?selftest=秒数[&hero=..&stage=..][&all=1]` — 描画なしで自動プレイし、結果をJSONで吐く
- `?demo=秒数[&ui=levelup|vault|result|hero]` — 指定秒数まで進めた戦況で時間を止める（絵の確認用）
- `?probe=vault|hero|forge` — 画面外にはみ出している要素を実測して列挙する
